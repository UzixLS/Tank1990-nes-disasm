# Аудиобайткод

Аудиодвижок хранит 28 указателей `AudioSequence00`–`AudioSequence27` в
`AudioSequencePointers`. Метки обозначают точки входа; последовательности
могут использовать общие хвосты. Таблица и сами потоки находятся в
`src/audio_data.s`, а интерпретатор команд — в `src/audio_engine.s`;
оба файла подключаются через контейнер `src/audio.s`.

При запуске потока читается заголовок из четырёх байт в поля 0, 1, 2 и 4
восьмибайтовой записи канала. Если поле 0 равно 4, следом читается пятый байт
для поля 3. После заголовка интерпретатор обрабатывает следующие токены.

## Токены

| Диапазон | Действие |
|---|---|
| `$00`–`$5F` | Нота: старшие пять бит выбирают базовый период, младшие три задают его сдвиг |
| `$60` | Завершить событие с текущей длительностью |
| `$61`–`$E7` | Записать длительность `token - $60` и читать следующий токен |
| `$E8`–`$F9` | Выполнить команду из `AudioCommandHandlers` |

## Команды

| Код | Операнд | Действие |
|---|---:|---|
| `$E8` | — | Остановить текущий слот и оставить позицию на маркере `$E8` |
| `$E9` | 1 байт | Заменить старшие два бита поля 1 |
| `$EA` | 1 байт | Заменить младшие шесть бит поля 1 |
| `$EB` | 1 байт | Заменить младшие четыре бита поля 1 |
| `$EC` | 1 байт | Записать поле 2 |
| `$ED` | 1 байт | Записать поле 4 |
| `$EE` | 1 байт | Записать поле 1 целиком |
| `$EF` | — | Сбросить три счётчика циклов |
| `$F0`–`$F2` | счётчик, позиция | Цикл со своим счётчиком; переход к абсолютной позиции внутри потока |
| `$F3`–`$F8` | 1 байт | Пропустить операнд; в этой версии отдельного эффекта нет |
| `$F9` | позиция | Перейти к абсолютной позиции внутри потока |

Позиции команд циклов отсчитываются от начала выбранной последовательности,
поэтому вставка байтов перед целью требует обновить соответствующий операнд.
