# Бонусы и их эффекты

## Жизненный цикл бонуса

Бонус создаётся при попадании в противника с установленным битом носителя. Новый бонус немедленно заменяет предыдущий, даже если тот ещё лежит на поле.

### Выбор позиции

Координаты X и Y независимо выбираются из:

```text
48, 96, 144, 192
```

Для каждой оси расходуется отдельный байт PRNG, из которого берутся два младших бита. Кандидат отвергается, если квадрат пересекается с подходящим активным танком:

```text
absWrapped(tank.x - bonus.x) < 12
AND
absWrapped(tank.y - bonus.y) < 12
```

В стандартных вариантах проверяются только P1/P2. В расширенных H–N — все восемь слотов. Допустимы состояния `0x80..0xDF`. При отказе обе координаты выбираются заново; число попыток не ограничено.

После успешного размещения третий байт PRNG выбирает исходный индекс 0..7.

### Набор типов

Если в меню включены все бонусы, индекс используется без изменения:

```text
[0, 1, 2, 3, 4, 5, 6, 7]
```

В ограниченном наборе применяется таблица:

```text
[0, 1, 2, 3, 3, 4, 5, 6]
```

Тип 7 отсутствует, а тип 3 имеет вероятность 2/8. Этот флаг не определяет, могут ли предметы подбирать противники: это отдельно определяется расширенным вариантом H–N.

## Отображение и подбор

Пока бонус лежит на поле, он мигает с фазой `frameCounter`: виден восемь кадров из каждых шестнадцати. Естественного тайм-аута нет. Он исчезает только при подборе или замене новым бонусом.

Подбор использует тот же квадрат расстояния `<12` по обеим осям. В A–G сканируются только игроки, в H–N — слоты 7..0, поэтому при одновременном пересечении более высокий номер противника получает предмет раньше игрока.

После подбора:

- эффект применяется немедленно;
- игрок получает 500 очков;
- противник очков не получает, но обычный звук подбора всё равно запускается;
- показывается маркер взятого предмета в течение 49 отрисованных кадров;
- затем координата X обнуляется и объект окончательно исчезает.

Внутренний служебный sentinel способен подавить 500 очков и звук, не подавляя эффект. В штатном игровом пути он не является пользовательской механикой.

## Таблица типов

Названия следуют официальной Battle City и распространённым обозначениям Tank 1990. Нормативным является номер и описанный эффект.

| Тип | Название | Игрок | Противник в H–N |
|---:|---|---|---|
| 0 | Helmet | щит на 10 медленных тактов | всем вражеским слотам HP=3 и инвертировать carrier bit |
| 1 | Clock | заморозить противников на 10 медленных тактов | оглушить обоих игроков на `0xC8` обслуживаний |
| 2 | Shovel | стальная защита базы на 20 медленных тактов | удалить ограждение и открыть целую базу |
| 3 | Star | повысить обычное оружие на один уровень | установить bit 3 всем вражеским атрибутам |
| 4 | Grenade | уничтожить все активные танки противника | уничтожить подходящих активных игроков |
| 5 | Tank | добавить одну жизнь | тот же глобальный эффект HP/carrier, что у типа 0 |
| 6 | Gun | установить максимальное оружие `0x63` | установить атрибут коллектора `0x63` |
| 7 | Boat/Ship | вода проходима, поглотить одно попадание | тот же специальный эффект для противника |

## Тип 0: Helmet

Игрок получает `shieldTimer = 10`. Таймер уменьшается один раз в медленный такт. Щит рисуется анимированными спрайтами и имеет высший приоритет среди защит при попадании: он не расходует Boat.

Если предмет взял противник, для всех слотов 2..7, включая неактивные:

```text
attributes = (attributes OR 0x03) XOR 0x04
```

То есть младшие два бита становятся 3, а бит носителя инвертируется. Высокий тип и bit 3 сохраняются.

## Тип 1: Clock

Игрок устанавливает общий `enemyFreezeTimer = 10` медленных тактов. Повторный Clock перезагружает длительность, не складывает её.

Противник устанавливает обоим игрокам `stunTimer = 0xC8`. Таймер каждого игрока уменьшается только в его обслуживаемые кадры. Повторный предмет перезагружает оба.

## Тип 2: Shovel

Игрок получает эффект только пока `battleState` обозначает активный бой:

1. оболочка базы немедленно становится стальной;
2. `baseFortificationTimer = 20` медленных тактов.

Последние три значения таймера 3, 2, 1 образуют предупреждение: оболочка чередует кирпич и сталь каждые 16 кадров. При завершении она становится кирпичной.

Противник:

- очищает ограждение в строках 25..27; строку 24 не трогает;
- рисует открытую целую базу;
- не обнуляет активный `baseFortificationTimer`.

Из-за последнего пункта предупреждающий цикл может позже снова нарисовать оболочку.

## Тип 3: Star

Обычные уровни игрока:

```text
0x00 -> 0x20 -> 0x40 -> 0x60
```

На `0x60` дальнейшие Star обычный уровень не повышают. Значение копируется в атрибут активного танка и меняет скорость, двойной выстрел и разрушение стали согласно декодеру снарядов.

Если включены все бонусы, каждая Star также увеличивает отдельный `extendedUpgrade` на `0x20` по модулю 256. Именно этот счётчик открывает специальное уничтожение леса при значении не меньше `0xA0`.

Противник устанавливает bit 3 (`attributes |= 0x08`) во всех слотах 2..7, включая ещё не появившиеся. В H–N этот бит даёт быстрый сильный снаряд.

## Тип 4: Grenade

Игрок переводит все активные целевые состояния противников `0x80..0xDF` непосредственно в уничтожение и обнуляет их атрибуты. При этом:

- очки не начисляются;
- счётчики четырёх типов не растут;
- носители не создают бонусы;
- уменьшение общего числа противников происходит позже, после анимаций.

Противник проверяет P2, затем P1. Активный игрок уничтожается только если его `stunTimer == 0`. Его обычное улучшение ставится в `0x20`, атрибут обнуляется. `extendedUpgrade` и Boat не очищаются этим эффектом. Звук уничтожения запрашивается даже при отсутствии цели.

## Тип 5: Tank

Игрок увеличивает число жизней на 1 по модулю 256 и запускает двухканальный звук дополнительной жизни.

Для противника эффект совпадает с типом 0: всем вражеским слотам выставляются три дополнительных HP и инвертируется carrier bit. Это необычие подтверждено кодом данного ROM.

## Тип 6: Gun

Игрок получает:

```text
playerUpgrade = 0x63
objectAttributes = 0x63
```

При включённых всех бонусах `extendedUpgrade += 0x60` по модулю 256. Максимальный атрибут допускает сильный выстрел и служит одноразовой бронёй: следующее попадание противника понижает обычный уровень до `0x40`, а не уничтожает танк.

Противник получает только `objectAttributes = 0x63`; общий массив вражеских слотов не меняется.

## Тип 7: Boat/Ship

У коллектора устанавливается специальный байт `0xFF`. Пока он ненулевой:

- рядом с танком рисуется специальный знак;
- вода `0x12` становится проходимой;
- следующее не поглощённое щитом попадание очищает специальный байт вместо уничтожения танка.

Boat не имеет таймера и сохраняется до попадания, обычной смерти либо явного сброса сессии. Вражеский эффект в H–N идентичен.

## Официальные и расширенные эффекты

Базовые предметы Battle City описаны в [официальном руководстве Nintendo](https://www.nintendo.co.jp/data/software/manual/man_FCTJ_00.pdf) [REF]. Gun, Boat и вражеские варианты эффектов относятся к Tank 1990; их точная семантика выше взята из кода данного образа [ROM].
