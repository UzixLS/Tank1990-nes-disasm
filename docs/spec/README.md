# Спецификация Tank 1990

## Назначение

Спецификация поведения образа `Tank 1990 (Ch).nes` для независимой реализации игры.

Спецификация описывает две ступени совместимости:

- **игровая совместимость** — совпадают правила, порядок обновления, уровни, режимы, управление, счёт, предметы и заметные временные характеристики;
- **покадровая совместимость** — дополнительно воспроизводятся целочисленные состояния, генератор псевдослучайных чисел, порядок коллизий, графические данные, палитры, звук и особенности оригинальной программы.

## Нормативность

Ключевые слова **ДОЛЖЕН**, **НЕ ДОЛЖЕН**, **СЛЕДУЕТ** и **МОЖЕТ** используются в обычном инженерном смысле:

- **ДОЛЖЕН** — требование игровой совместимости;
- **НЕ ДОЛЖЕН** — наблюдаемое поведение, которое нельзя менять в совместимом режиме;
- **СЛЕДУЕТ** — рекомендуемый способ получить близкий результат;
- **МОЖЕТ** — свобода реализации без заметного расхождения.

Требования с пометкой **[точная совместимость]** нужны только для второй ступени.

## Источники фактов

Каждое существенное правило относится к одному из классов:

| Метка | Значение | Приоритет |
|---|---|---:|
| `[ROM]` | подтверждено исполняемым кодом или таблицами данного образа | 1 |
| `[DATA]` | подтверждено извлечёнными ресурсами данного образа | 2 |
| `[REF]` | подтверждено официальным описанием Battle City | 3 |
| `[WEB]` | вторичный интернет-источник о Tank 1990 или Battle City | 4 |
| `[INF]` | вывод из нескольких наблюдений или общепринятое имя | 5 |

При противоречии действует источник с меньшим номером приоритета.

## Термины и координаты

- **Кадр** — один вызов NMI и один логический такт NTSC, приблизительно 1/60 секунды.
- **Медленный такт** — увеличение отдельного счётчика один раз в 64 кадра.
- **Тайл** — элемент фона 8×8 пикселей.
- **Метатайл** — ячейка карты 16×16 пикселей, состоящая из четырёх тайлов.
- **Подячейка** — четверть метатайла 8×8; кирпич и сталь разрушаются ещё точнее, блоками 4×4.
- **Центр объекта** — логическая координата танка, снаряда или бонуса. Для танка размером 16×16 видимый прямоугольник относительно центра равен `[-8,+7]` по обеим осям.
- Начало координат экрана находится слева сверху; `X` растёт вправо, `Y` вниз.
- Игровое поле занимает экранные тайлы `X=2..27`, `Y=2..27`, то есть 26×26 тайлов или 13×13 метатайлов.

Числа с префиксом `0x` шестнадцатеричные. Если явно не сказано обратное, арифметика точной модели выполняется беззнаковыми 8-битными числами с переполнением по модулю 256.

## Границы воспроизведения

Спецификация не требует копировать аппаратную организацию NES, язык 6502 или расположение RAM. Разрешены современные движки, плавающая частота отрисовки и любое внутреннее представление, если логика симулируется фиксированным тактом и проходит критерии приёмки.

Игровая совместимость не охватывает проверки целостности ROM, неиспользуемые точки входа, повреждённый стек, недопустимые индексы таблиц и размещение кода в PRG.
