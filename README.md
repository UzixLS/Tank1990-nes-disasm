# Tank 1990 (Ch)

Исходный код и ассеты NES-игры `Tank 1990 (Ch).nes`. Сборка ca65/ld65
побайтово совпадает с исходным образом.

## Сборка и проверка

Требуются GNU Make 4.3+, cc65 2.19 и Python 3.12 без сторонних пакетов.
Локальные пути к инструментам задаются в игнорируемом `Makefile.local`;
пример — `Makefile.local.example`.

| Команда | Результат |
|---|---|
| `make all` | ROM `build/tank1990-ch.nes` |
| `make test-tools` | Тесты конвертеров ассетов |
| `make verify` | Побайтовое сравнение сборки с оригиналом и проверка SHA-256 |
| `make test` | Тесты конвертеров, ассетов и загрузчика карт |
| `make audit` | Проверка разметки PRG, переходов и каталога карт; отчёты в `build/` |
| `make level-screenshots` | Изображения карт в `build/level-screenshots/` |
| `make clean` | Удаление `build/` |

`make all`, `make test-tools` и `make level-screenshots` работают без исходного
ROM. Для `make verify`, `make test-assets`, `make test` и `make audit` нужен
`Tank 1990 (Ch).nes` с SHA-256
`ec453e7e3cc1d49d11d5860ced7f9e1235e2c7d33927bd6073b631754dc08dbb`.
Эти проверки рассчитаны на точное восстановление оригинала.

## Ассеты

| Путь | Формат и содержимое |
|---|---|
| `assets/chr/*.bmp` | Две таблицы по 256 тайлов: несжатые индексированные BMP 128×128, 8 бит, индексы 0–3 |
| `assets/palettes/*.pal` | Палитра спрайтов и девять фоновых наборов; индексы цветов NES `00`–`3F` |
| `assets/metatiles/background.tsa` | 16 метатайлов: подпалитра и четыре индекса фоновых тайлов |
| `assets/levels/classic/*.map` | 36 карт штатного каталога загрузчика |
| `assets/levels/extra/*.map` | 105 карт PRG0, на которые штатные дескрипторы не ссылаются |
| `assets/levels/unused/001.map` | Карта по адресу `$A800` без статических ссылок |

Карта содержит 13 строк по 13 шестнадцатеричных индексов метатайлов.
Значение после `|` сохраняет неиспользуемый полубайт исходного формата.
Всего в ROM 142 записи и 107 различных карт; состав и адреса описаны в
[проверках ROM и карт](docs/audit.md).

`make level-screenshots` рисует поле 13×13 метатайлов из текущих ассетов
с фоновым набором палитры 0, без базы, танков и HUD. Изображения повторяют
структуру `assets/levels`; цвета — фиксированное RGB-приближение палитры NES.
Масштаб по умолчанию ×2 (416×416), параметр `LEVEL_SCALE=1` даёт 208×208;
допустимы значения 1–8. Для этой цели cc65 не нужен.

## Исходники и документация

Код разделён по игровым подсистемам в `src/`. Порядок `.include` и
конфигурация `cfg/tank1990.cfg` сохраняют адреса оригинального ROM.
Общие переменные RAM находятся в `src/ram.inc`, константы — в `src/game.inc`.
Метки `Lxxxx` обозначают исходные CPU-адреса; для нового кода используются
смысловые имена процедур, таблиц и переменных.
