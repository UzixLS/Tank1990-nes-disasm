Tank 1990 - игра для Famicom (NES), хак игры Battle City.

Файл Tank 1990 (Ch).nes - исходный образ
Файл BC_SourceCode.asm - дизассемблированный аннотированный исходник Battle City (для референса)

Служебные скрипты пишем на Python, размещаем в каталоге tools\
При написании предпочитай простой лаконичный минималистичный код

Ghidra + PyGhidra + GhidraNes установлены в C:\Programs\ghidra\
CC65 (assembler/disassembler/etc) - C:\Hwdev\cc65\
Make и Unix tools - C:\Dev\msys64\
Верхний уровень для запуска pipeline - используем Makefile
